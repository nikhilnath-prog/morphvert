# Morphvert: AI PDF Summarizer & Organize PDF

## What's included
- **AI PDF Summarizer**: Short, detailed, or complete summaries (overview + detailed summary + key takeaways) generated by Gemini.
- **Organize PDF**: Reorder pages, rotate pages (0/90/180/270 degrees), and delete pages.
- **Merge PDF**: Existing merge tool remains available; uploaded files can be reordered in its existing workflow before merging.

## Run locally (Windows)

> Use **Python 3.12**. Python 3.14 may fail to build pinned dependencies such as `pydantic-core`.

### 1. Backend (FastAPI)
Open a terminal at the project root (`D:\Morphvert-Updated`) and run:

```powershell
cd backend
# If you already created a venv with Python 3.14, remove it first:
if (Test-Path .venv) { Remove-Item -Recurse -Force .venv }
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

The ZIP includes a local `backend/.env` with a development-only `SECRET_KEY` and local CORS origins, so the API can start without manually exporting `SECRET_KEY`. Replace the key before deployment. For AI summaries, open `backend/.env` and set `GEMINI_API_KEY` to your Google AI Studio key. Never put that key in the frontend.

Start the API from the **backend** folder:

```powershell
.\.venv\Scripts\python.exe -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

Check `http://127.0.0.1:8000/health` — it should return `{"status":"healthy",...}`.

### 2. Frontend (React + Vite)
Open a **second** terminal at the project root:

```powershell
cd frontend
npm install
npm run dev
```

`frontend/.env.local` is preconfigured to use `http://127.0.0.1:8000`. If you change the API URL, restart Vite after editing this file. Open the local URL printed by Vite (usually `http://localhost:5173`).

The API client now defaults to the local backend instead of the hosted production URL, and the backend allows the local Vite origins. This addresses the common “Network error / check backend connection” issue when running the project locally.

Find **AI PDF Summarizer** under AI Tools and **Organize PDF** under Organize. **Merge PDF** remains under Organize.

## API endpoints
- `POST /api/v1/ai/pdf/summarize` — multipart fields: `file`, `mode` (`all`, `short`, `detailed`)
- `POST /api/v1/pdf/info` — multipart field: `file`; returns page count
- `POST /api/v1/pdf/organize` — multipart fields: `file`, `order` (JSON list of one-based page numbers), `rotations` (JSON map of page number to degrees), `delete_pages` (JSON list of one-based page numbers); returns PDF bytes

PDF endpoints enforce a 50 MB upload limit. Summarization currently extracts selectable PDF text; scanned/image-only PDFs return a clear error and require OCR before they can be summarized.
